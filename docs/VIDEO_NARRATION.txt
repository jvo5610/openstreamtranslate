OpenStreamTranslate is an open source live captioning system for conferences.
It transcribes English or Spanish audio, translates in both directions, and
keeps the captions inside the video, where the audience expects them.

Here, a real Nerdearla talk is streamed at normal speed. The viewer can choose
the stage, mute the original audio, pause the live experience, and select the
original or translated caption track with a familiar C C menu. The same player
also handles an English source and renders Spanish captions.

This is how I connect a real production source. O B S or vMix publishes one
R T M P or S R T stream per stage to the media server. The video continues to
H L S or Web R T C for the audience. In parallel, the included F F mpeg bridge
extracts only mono sixteen-kilohertz audio and sends it over a binary WebSocket
to a stable session identifier. Replacing the simulated publisher with O B S
only requires the server address and stream key; OpenStreamTranslate does not
need to change.

FastAPI sends caption events through Redis Streams and Pub Sub. The browser
receives them over reconnectable server-sent events, while an O B S browser
source can use the transparent overlay. Final captions can be downloaded as
S R T, V T T, or plain text.

The pipeline uses large-v-three-turbo and TranslateGemma locally. In the
reproducible checks it reached three point seven percent English word error
rate, handled ten simultaneous stages, and distributed one shared caption to
one thousand viewers with one hundred seventy-three milliseconds p ninety-five
fan-out latency.

The key design decision is simple: inference scales with active stages, not
with audience size. OpenStreamTranslate is reproducible, observable, and ready
to connect to a real conference streaming chain.
